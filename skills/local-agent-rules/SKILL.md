# 本机 Agent 通用规则

## 1. 加载范围与本机配置

- 本 skill 是通用操作规范，不授予额外权限，不覆盖系统约束、用户当前指令或项目已有规则。
- 先确认当前项目、工作树、任务范围和运行环境；不要假定不同机器、项目或远程环境具有相同配置。
- 本机专属信息只从本地文件 `~/.config/local-agent-rules/machine.md` 读取；不存在时按项目配置和实际探测结果执行，不猜测服务器、凭据或工具版本。
- 只读取这份明确的本机配置，不为寻找 Token 扫描环境、历史记录、钥匙串、认证文件或 SSH 私钥。
- 不把本机配置、公司地址、主机信息或敏感凭据复制进本 skill 仓库。通用流程在仓库维护，本机差异留在本地。
- 纯聊天且不操作本机时无需执行环境检查；已经完整加载的规则不重复读取。

## 2. 代码检索与 CodeGraph

- 已有 CodeGraph 索引的项目，先确认索引属于当前项目或 worktree 且足够新，再优先使用 CodeGraph。
- 每个项目在本会话首次查询前、切换分支或批量变更后、工具提示过期时，按 [CodeGraph 索引维护](references/codegraph.md) 检查。
- 普通代码增删改和分支切换优先增量 `sync`，不默认全量 `index`。
- 未建立索引时默认用常规文件读取和搜索；只有用户已授权初始化且权限允许时才 `init`。
- 当前项目没有索引时，不因别的项目已接入 MCP 就继续查询错误的索引。
- MCP 使用 `codegraph_explore`，通过 `projectPath` 指定实际项目或 worktree 的绝对路径；必要时先加载工具。
- MCP 不可用时，在目标项目使用 `codegraph explore "<符号名或问题>"`；工具不可用或结果不新时退回源码。

## 3. 本机开发环境

- 优先遵循项目已有的版本配置与构建方式，不为了方便切换用户的全局默认版本。
- 执行项目前，按需用 `command -v java`、`command -v python`、`command -v python3`、`command -v mvn`、`command -v node` 确认命令来源；只检查当前任务需要的运行时。
- 使用本机配置指定的版本管理器；若指定 mise、nvm 或 pyenv，先检查当前有效版本，再决定是否切换或安装。
- `mise current` / `mise ls`、`nvm ls` / `node -v`、`pyenv versions` 可用于核对，不能仅凭安装记录认定 PATH 已生效。
- 找不到命令时先检查非交互式 shell 的初始化和 PATH；不直接认定未安装，也不运行来源不明的初始化脚本。
- 安装或切换运行时使用对应版本管理工具，不用系统包管理器覆盖已有的 Java、Python、Maven、Node.js。

## 4. Maven 测试范围

- 只运行与当前改动相关的单元测试，不默认执行全量测试。
- 按需限定模块、测试类或测试方法，例如 `mvn -Dtest=ExampleTest test`；实际命令须符合项目现有测试配置。
- 确需扩大测试范围时，先说明原因并征得用户同意。
- 只验证了定向测试时，如实报告测试范围，不宣称全量回归通过。

## 5. SSH 连接与远程排查

- 目标主机、用户、端口与密钥路径必须来自当前任务授权或本机配置，不内置任何个人或公司服务器信息。
- 可在授权目标上尝试指定的诊断密钥或默认 SSH 密钥；使用 `BatchMode=yes` 避免等待交互式密码。
- 不读取、展示或复制私钥内容，不把密钥材料放进命令参数或仓库。
- 不扫描或尝试登录无关服务器，不把“密钥可用”当成“操作已获授权”。
- 排查优先只读。重启、部署、修改配置或数据等操作必须在明确授权范围内执行。
- 主机指纹或证书校验失败时停止并核实，不自动关闭校验或删除 `known_hosts` 记录。

## 6. Git 平台与凭据安全

- GitHub 优先使用 GitHub CLI（`gh`），API 请求使用 `gh api`；GitLab 优先使用 API，不优先使用 Computer Use。
- 具体 GitLab 地址与 Token 环境变量名以本机配置或任务说明为准；GitHub 可使用运行时已有的 `GITHUB_TOKEN`。
- 认证失败时说明缺少认证或权限，不索要用户把 Token 明文贴进聊天，不擅自创建凭据。
- 不输出 Token 值，不开启可能泄露认证信息的 shell trace 或 HTTP verbose，不将 Token 嵌入 URL、Git remote、代码、文档、提交或日志。
- 不读取 SSH 私钥、Token 文件或其他认证存储来“验证配置”；优先通过认证状态或最小权限只读请求验证。
- 若凭据已在聊天、日志或仓库暴露，提示撤销并换新，不把它持久化或传播给其他 Agent。
- API 调用、提交、推送、远程执行均遵守当前授权范围；安装此 skill 不代表获得自动提交、推送或修改远程系统的权限。

## 7. 完成与验证

- 只报告实际完成的操作、检查结果和未完成项；入口配置成功不等同于模型已加载或流程已执行。
- 当前任务用到本机配置时确认其已读取；依赖 CodeGraph 时确认项目路径、索引状态和同步结果。
- Token、密钥和本机私有配置不得进入待提交文件。
- Skill 是按需加载的操作规范，不是 watcher、计划任务或 hook。需要确定性事件自动化时须另行配置、验证并保留现有 hook。
- 多 Agent 安装、全局入口和版本更新方式见 [安装与接入](references/setup.md)。
